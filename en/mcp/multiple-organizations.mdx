---
title: 'Multiple organizations'
description: 'Work with all your ContactShip organizations from a single connection of your AI assistant.'
---

Every ContactShip API key belongs to a single organization. One MCP connection can carry the keys of **up to 10 organizations**: you connect once and the assistant works in any of them, or in all of them at once when you ask for an overview.

---

## Connect several organizations

### Claude.ai (web) and ChatGPT

<Steps>
  <Step title="Add the connector">
    In Claude.ai, **Settings > Integrations > Add custom connector**, with the URL `https://mcp.contactship.ai/mcp`. See [MCP in Claude (web)](/en/mcp/claude).
  </Step>
  <Step title="Paste the first key">
    On the ContactShip screen that opens, paste the API key of one of your organizations. Below the field you see which organization it is.
  </Step>
  <Step title="Add the others">
    Hit **Add another organization** and paste the next one. If you copied several keys together, one per line, paste them all at once: each lands in its own row.
  </Step>
  <Step title="Connect">
    The button says how many organizations you are connecting, for example **Connect 3 organizations**.
  </Step>
</Steps>

<Note>
If you already connected ContactShip with a single organization, disconnect the connector and connect it again pasting every key. The keys are stored encrypted inside the connection, so they cannot be edited afterwards.
</Note>

### Claude Code

Separate the keys with commas in the same header:

```bash
claude mcp add-json contactship '{"type":"sse","url":"https://mcp.contactship.ai/sse","headers":{"x-api-key":"ACME_KEY,BETA_KEY"}}'
```

If you already had the `contactship` connection, remove it first with `claude mcp remove contactship`.

### Cursor and Claude Desktop

The same in `.cursor/mcp.json` or `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "contactship": {
      "url": "https://mcp.contactship.ai/sse",
      "headers": { "x-api-key": "ACME_KEY,BETA_KEY" }
    }
  }
}
```

## How to ask

**For one organization, name it:**

> "In Acme, show today's unanswered conversations"

**To see all of them, ask without naming one.** Overviews ask every organization and answer each one separately:

> "Which conversations are still unanswered today?"

> "Which organization is Ana Pérez in, and what happened with her?"

This works for unanswered conversations, tasks, call summaries and call search, contact search, agents, channels and numbers, and inbox metrics.

**To change something, the assistant needs to know where.** Sending a WhatsApp message, editing or publishing an agent, placing a call or closing a conversation always happens in one organization: if you did not name it, the assistant asks which one before doing anything.

To see which organizations the connection reaches, ask "which organizations are connected?".

---

## Keep in mind

- **Each key still sees only its organization.** Every action runs with the key of a single organization, even with all of them in the same connection.
- **Up to 10 organizations per connection.** If you need more, use more than one connection (see below) or contact [support](/en/get-started/support).
- **If you regenerate an organization's key**, update the connection: in Claude.ai reconnect the connector with every key; in Claude Code or Cursor replace that key in the header.
- **Two organizations with the same name** are told apart by the start of their id, for example `Demo (3f2a9c1e)`.

---

## One connection per organization

You can also connect ContactShip once per organization, each connection with its own key and a distinct name (for example `contactship-acme` and `contactship-beta`). It helps if you have more than 10 organizations or prefer each one to appear separately. Each connection adds ContactShip's full tool set to the assistant, so with many connections it chooses more slowly and uses more context on every message.
