Create a voice agent and automatically publish its first version.

## Authentication

<ParamField header="x-api-key" type="string" required>Organization API key. Keep it on your server or in a credential store.</ParamField>

Provide a valid voice ID and IANA time zone. Creation publishes version 1, so prepare the prompt before attaching a number, campaign, or widget.

## Body

The first three fields are required; remaining fields are optional.

<ParamField body="name" type="string" required>Internal name.</ParamField>
<ParamField body="voice_id" type="string" required>ID from List voices.</ParamField>
<ParamField body="timezone" type="string" required>IANA time zone, such as `America/Mexico_City`.</ParamField>
<ParamField body="person_name" type="string">In-call name.</ParamField>
<ParamField body="language" type="string">Supported language code, such as `en-US`, `es-ES`, `es-419`, or `multi` (Spanish and English).</ParamField>
<ParamField body="conversation_purpose" type="string">Conversation objective.</ParamField>
<ParamField body="prompt" type="string">Instructions, up to 28,000 characters.</ParamField>
<ParamField body="webhook_url" type="string">Outgoing webhook URL.</ParamField>
<ParamField body="ambient_sound" type="string">`coffee-shop`, `convention-hall`, `summer-outdoor`, `mountain-outdoor`, `static-noise`, or `call-center`.</ParamField>
<ParamField body="voice_speed" type="number">API range 0.5–2; the app slider exposes a narrower range.</ParamField>
<ParamField body="voice_temperature" type="number">0–2.</ParamField>
<ParamField body="volume" type="number">0–2.</ParamField>
<ParamField body="ambient_sound_volume" type="number">0–2.</ParamField>
<ParamField body="responsiveness" type="number">0–1.</ParamField>
<ParamField body="interruption_sensitivity" type="number">0.1–1.</ParamField>
<ParamField body="begin_message" type="string">Opening phrase, up to 240 characters.</ParamField>
<ParamField body="begin_message_delay_ms" type="number">0–5,000 milliseconds.</ParamField>
<ParamField body="max_call_duration_ms" type="number">Requested maximum call duration in milliseconds, subject to plan limits.</ParamField>
<ParamField body="boosted_keywords" type="string[]">Terms to improve recognition.</ParamField>
<ParamField body="post_call_analysis_data" type="object[]">Extraction definitions with string, enum, boolean, or number type.</ParamField>
<ParamField body="tools" type="object[]">Tool definitions: booking, transfer_call, custom, end_call, or agent_swap. Use the schema for the selected tool type; changing an array can replace its configuration.</ParamField>

## Example

Replace VOICE_ID with a current catalog ID.

```bash
curl -X POST 'https://api.contactship.ai/v1/agents'   -H 'x-api-key: YOUR_API_KEY' -H 'Content-Type: application/json'   -d '{"name":"Showroom assistant","voice_id":"VOICE_ID","timezone":"America/Mexico_City","person_name":"Ana","language":"es-419","conversation_purpose":"Answer showroom questions.","prompt":"Answer only with the business information provided. Ask a person for help when information is missing."}'
```

## Response

Successful creation returns HTTP 201 with `statusCode` and `data`. The identifier is `data.id`, not `agent_id`. See [Get agent](/api-reference/endpoint/get-agent) for response fields and [List voices](/api-reference/endpoint/list-voices) for voice IDs.
