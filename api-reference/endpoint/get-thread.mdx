---
title: 'Get Thread'
api: 'GET /v1/thread/{threadId}'
description: 'Retrieve a conversation thread by its ID'
---

Returns the details of a specific conversation thread, including its channel, contact, status, assignee and, when the conversation started from a Meta ad or post, its `referral`.

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="threadId" type="string" required>
  The UUID of the thread to retrieve.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique identifier of the thread (UUID).
</ResponseField>

<ResponseField name="channel_id" type="string">
  UUID of the channel this thread belongs to.
</ResponseField>

<ResponseField name="channel_type" type="string">
  Type of the channel (e.g. `WABA`, `INSTAGRAM`).
</ResponseField>

<ResponseField name="contact_id" type="string">
  UUID of the contact in this thread.
</ResponseField>

<ResponseField name="organization_id" type="string">
  UUID of the organization that owns this thread.
</ResponseField>

<ResponseField name="status" type="string">
  Thread status (e.g. `open`, `closed`).
</ResponseField>

<ResponseField name="assignee" type="string">
  UUID of the user or agent currently assigned to this thread.
</ResponseField>

<ResponseField name="assignee_type" type="string">
  Type of the assignee: `user` or `agent`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Timestamp when the thread was created (ISO 8601).
</ResponseField>

<ResponseField name="updated_at" type="string">
  Timestamp of the last update (ISO 8601).
</ResponseField>

<ResponseField name="referral" type="object | null">
  Where the conversation came from, as Meta reported it in the contact's first message. Present when someone wrote from a Click-to-WhatsApp ad, a post or a page; `null` for organic conversations. Fields Meta did not send are left out, so check each one before using it.
  <Expandable title="Referral object">
    <ResponseField name="source_type" type="string">What the contact clicked: `ad`, `post` or `page`.</ResponseField>
    <ResponseField name="source_id" type="string">Meta ID of the ad or post. For ads, this is the ad ID in Ads Manager.</ResponseField>
    <ResponseField name="source_url" type="string">Link to the ad or post on Facebook or Instagram.</ResponseField>
    <ResponseField name="ctwa_clid" type="string">Click ID of the Click-to-WhatsApp ad. Use it with the Meta Conversions API to attribute a lead or a purchase to the ad (see below). Meta omits it in some cases, such as ads shown in WhatsApp Status.</ResponseField>
    <ResponseField name="headline" type="string">Ad or post headline.</ResponseField>
    <ResponseField name="body" type="string">Ad or post text.</ResponseField>
    <ResponseField name="media_type" type="string">Type of media in the ad: `image` or `video`.</ResponseField>
    <ResponseField name="image_url" type="string">Image of the ad, when `media_type` is `image`.</ResponseField>
    <ResponseField name="video_url" type="string">Link to the video of the ad, when `media_type` is `video`.</ResponseField>
    <ResponseField name="thumbnail_url" type="string">Thumbnail of the video, when `media_type` is `video`.</ResponseField>
    <ResponseField name="welcome_message" type="object">Pre-filled message the ad suggested to the contact, as `{ "text": "..." }`.</ResponseField>
    <ResponseField name="ref" type="string">Custom `ref` parameter of the link, when the ad or the link set one.</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  `image_url`, `video_url` and `thumbnail_url` are signed Meta URLs and expire after a few days. Download the media when you receive it if you need to keep it; don't store the URL.
</Warning>

## Ad attribution with the Conversions API

`referral.ctwa_clid` is the identifier Meta asks for to attribute a conversion from a WhatsApp conversation to the ad that started it. When the contact converts (a lead, a purchase), send the event to the [Conversions API](https://developers.facebook.com/docs/marketing-api/conversions-api/business-messaging) of your dataset with:

- `action_source`: `business_messaging`
- `messaging_channel`: `whatsapp`
- `user_data.ctwa_clid`: the `ctwa_clid` of the thread
- `user_data.whatsapp_business_account_id`: the ID of your WhatsApp Business account

```bash
curl -X POST "https://graph.facebook.com/v21.0/{DATASET_ID}/events?access_token={TOKEN}"   -H "Content-Type: application/json"   -d '{
    "data": [{
      "event_name": "Purchase",
      "event_time": 1775487600,
      "action_source": "business_messaging",
      "messaging_channel": "whatsapp",
      "user_data": {
        "ctwa_clid": "ARAkLkA8rmlFeiCktEJQ-QTwRiyYHAFDLMNDBH0CD3qpjd0HR4irJ6LEkR7JwFF4XvnO2E4Nx0-eM-GABDLOPaOdRMv-_zfUQ2a",
        "whatsapp_business_account_id": "1234567890123456"
      },
      "custom_data": { "currency": "USD", "value": 49.9 }
    }]
  }'
```

`referral.source_id` is the ad ID: use it to match the conversation with the ad's results in Ads Manager.

## Error Codes

- `401 Unauthorized` — Invalid or missing API key
- `404 Not Found` — Thread not found or does not belong to your organization
- `500 Internal Server Error` — Server-side error

## Code Examples

<RequestExample>
```bash cURL
curl -X GET "https://api.contactship.ai/v1/thread/thr-b2c3d4e5-f6a7-8901-bcde-f12345678901" \
  -H "x-api-key: your-api-key"
```

```javascript JavaScript
const threadId = 'thr-b2c3d4e5-f6a7-8901-bcde-f12345678901';
const response = await fetch(
  `https://api.contactship.ai/v1/thread/${threadId}`,
  { headers: { 'x-api-key': 'your-api-key' } }
);
const thread = await response.json();
console.log(`Thread status: ${thread.status}`);
```

```python Python
import requests

thread_id = 'thr-b2c3d4e5-f6a7-8901-bcde-f12345678901'
response = requests.get(
    f'https://api.contactship.ai/v1/thread/{thread_id}',
    headers={'x-api-key': 'your-api-key'},
)
print(response.json())
```
</RequestExample>
