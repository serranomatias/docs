Retrieve the organization’s current credit balance.

## Authentication

<ParamField header="x-api-key" type="string" required>Organization API key. Keep it on your server or in a credential store.</ParamField>

This read-only request is useful for checking authentication before configuring write operations.

```bash
curl 'https://api.contactship.ai/v1/credits'   -H 'x-api-key: YOUR_API_KEY'
```

## Response

<ResponseField name="statusCode" type="number">200 on success.</ResponseField>
<ResponseField name="data.credits" type="number">Current credit balance returned for the organization.</ResponseField>

The balance is not a remaining-minute count. Actual consumption depends on the product and applicable rate. Review usage and payments in [Billing](/en/billing/credits-and-payments).
