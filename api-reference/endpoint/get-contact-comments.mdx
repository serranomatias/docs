---
title: "Get Contact Comments"
api: "GET /v1/contacts/{contactId}/comments"
description: "Read comments associated with a contact in your organization."
---

Retrieve the comments for a contact. Use [Create comment](/api-reference/endpoint/create-comment) to add a new entry.

<ParamField header="x-api-key" type="string" required>Your organization API key.</ParamField>
<ParamField path="contactId" type="string" required>The contact UUID.</ParamField>

This endpoint does not expose pagination or sorting query parameters.

## Response

<ResponseField name="statusCode" type="number">200 on success.</ResponseField>
<ResponseField name="data.total_comments" type="number">Number of comments returned.</ResponseField>
<ResponseField name="data.comments" type="object[]">Comments with `id`, `content`, `created_by`, and `created_at`. The creator may be a user object or a source identifier; do not assume a separate `user_name` field.</ResponseField>

<RequestExample>
```bash cURL
curl 'https://api.contactship.ai/v1/contacts/CONTACT_ID/comments' \
  -H 'x-api-key: YOUR_API_KEY'
```

```javascript JavaScript
const response = await fetch(
  `https://api.contactship.ai/v1/contacts/${encodeURIComponent(contactId)}/comments`,
  { headers: { 'x-api-key': apiKey } },
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { data } = await response.json();
console.log(data.total_comments, data.comments);
```
</RequestExample>
