---
title: "Find Call History by Phone Number"
description: "Resolve a phone number to a contact ID, then retrieve that contact’s call history."
---

Call history requires a **contact ID**. Do not put a phone number directly in `/v1/contacts/{contactId}/call-history`.

## 1. Find the contact

Use [Get contact by identifier](/api-reference/endpoint/get-contact-by-identifier) with `identifierType=phone_number` and the URL-encoded international phone number. Read the returned contact ID.

## 2. Retrieve history

Use that ID with [Get contact call history](/api-reference/endpoint/get-contact-call-history):

```bash
curl 'https://api.contactship.ai/v1/contacts/CONTACT_ID/call-history' \
  -H 'x-api-key: YOUR_API_KEY'
```

If no contact matches, check the organization and number format before creating or changing records. For date, status, or other call filters, use [List calls](/api-reference/endpoint/list-calls) with its documented query parameters.
