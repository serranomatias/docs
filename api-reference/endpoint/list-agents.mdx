List voice agents for the organization associated with the API key.

## Authentication

<ParamField header="x-api-key" type="string" required>Organization API key. Keep it on your server or in a credential store.</ParamField>

```bash
curl 'https://api.contactship.ai/v1/agents' -H 'x-api-key: YOUR_API_KEY'
```

<ResponseField name="statusCode" type="number">200 on success.</ResponseField>
<ResponseField name="data" type="object[]">Published voice-agent records. Each entry uses the fields in [Get agent](/api-reference/endpoint/get-agent).</ResponseField>

Use each record’s `id` for subsequent requests. This endpoint has no documented pagination parameters. Voice IDs come from [List voices](/api-reference/endpoint/list-voices), not from this list’s agent IDs.
