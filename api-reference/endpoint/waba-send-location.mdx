---
title: 'Send WhatsApp Location'
api: 'POST /v1/waba/send-location'
description: 'Send a location pin to a contact via WhatsApp Business API'
---

Sends a location message (map pin) to a contact through a WABA channel. The contact will receive an interactive map pin in WhatsApp.

<Note>
  A location is a free-form message: WhatsApp only delivers it within the 24-hour window that opens when the contact writes to you. To start a conversation, use [Send WhatsApp Template](/api-reference/endpoint/waba-send-template).
</Note>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication.
</ParamField>

## Body

Send `channel_id` + `contact_id`, or `thread_id`.

<ParamField body="channel_id" type="string">
  ID of the WABA channel to send from. Required unless you send `thread_id`. Use [List Channels](/api-reference/endpoint/get-channels) to get available channel IDs.
</ParamField>

<ParamField body="contact_id" type="string">
  UUID of the contact to message. Required unless you send `thread_id`.
</ParamField>

<ParamField body="latitude" type="number" required>
  Latitude of the location, between -90 and 90 (e.g. `19.4326`).
</ParamField>

<ParamField body="longitude" type="number" required>
  Longitude of the location, between -180 and 180 (e.g. `-99.1332`).
</ParamField>

<ParamField body="name" type="string">
  Name of the location (e.g. `ContactShip HQ`). Displayed as the pin title.
</ParamField>

<ParamField body="address" type="string">
  Address of the location (e.g. `Paseo de la Reforma 505, CDMX`). Displayed below the pin title.
</ParamField>

<ParamField body="thread_id" type="string">
  UUID of an existing thread. If provided, `channel_id` and `contact_id` are inferred automatically.
</ParamField>

<ParamField body="save_message" type="boolean" default="true">
  Whether to save the message in the conversation thread.
</ParamField>

## Response

The response is `{ "statusCode": number, "data": object }`. The fields below describe `data`.

<ResponseField name="success" type="boolean">
  `true` if the location was sent successfully.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable result.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Response data">
    <ResponseField name="message_id" type="string">Internal UUID of the message record.</ResponseField>
    <ResponseField name="provider_id" type="string">WhatsApp message ID returned by Meta.</ResponseField>
    <ResponseField name="thread_id" type="string">UUID of the conversation thread.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

- `400 Bad Request` — Missing fields (`latitude`, `longitude`, or `channel_id` + `contact_id` without `thread_id`), coordinates out of range, unknown body fields, or a non-WABA channel; or Meta rejected the request (`message` carries the reason Meta gave, for example an expired channel token or a closed 24-hour window)
- `401 Unauthorized` — Invalid or missing API key
- `403 Forbidden` — Channel does not belong to your organization
- `404 Not Found` — Contact not found
- `429 Too Many Requests` — Rate limit; retry after a pause
- `500 Internal Server Error` — Server-side error
- `502 Bad Gateway` — Meta API unavailable; safe to retry
