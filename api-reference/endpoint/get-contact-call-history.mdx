---
title: "Get Contact Call History"
api: "GET /v1/contacts/{contactId}/call-history"
description: "Retrieve a contact and its call-history summary using the contact ID."
---

Retrieve the contact and its call history within the organization associated with your API key. To start from a phone number, [resolve the contact ID first](/api-reference/endpoint/get-contact-call-history-by-phone).

<ParamField header="x-api-key" type="string" required>Your organization API key.</ParamField>
<ParamField path="contactId" type="string" required>The contact UUID.</ParamField>

This route does not expose date, direction, or status query filters. Use [List calls](/api-reference/endpoint/list-calls) when you need those filters.

## Response

The response uses the standard `statusCode` and `data` envelope.

<ResponseField name="statusCode" type="number">HTTP status of the successful request.</ResponseField>
<ResponseField name="data.contact" type="object">The contact associated with this history.</ResponseField>
<ResponseField name="data.call_history" type="object">
  The history summary, containing `call_attempts`, `last_call`, and `calls`.
</ResponseField>
<ResponseField name="data.call_history.call_attempts" type="number">Number of recorded call attempts.</ResponseField>
<ResponseField name="data.call_history.last_call" type="object">Most recent call when history is available.</ResponseField>
<ResponseField name="data.call_history.calls" type="object[]">
  Recorded calls. Fields include `direction`, `status`, `duration` (string), `from`, `call_record`, `start_at`, `finished_at`, `price`, `price_unit`, `call_analysis`, `type`, `created_at`, and `chat_history`. Recording, analysis, and timing values depend on the call; handle unavailable values before rendering them.
</ResponseField>

<RequestExample>
```bash cURL
curl 'https://api.contactship.ai/v1/contacts/CONTACT_ID/call-history' \
  -H 'x-api-key: YOUR_API_KEY'
```

```javascript JavaScript
const response = await fetch(
  `https://api.contactship.ai/v1/contacts/${encodeURIComponent(contactId)}/call-history`,
  { headers: { 'x-api-key': apiKey } },
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { data } = await response.json();
const calls = data.call_history?.calls ?? [];
console.log(calls);
```
</RequestExample>

Check the API key and selected organization if the contact cannot be found. A successful response confirms the lookup; it does not imply that every call has a recording or completed analysis.
