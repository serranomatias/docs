---
title: 'Varias organizaciones'
description: 'Trabajá con todas tus organizaciones de ContactShip desde una sola conexión de tu asistente de IA.'
---

Cada API key de ContactShip pertenece a una sola organización. Una conexión del MCP puede llevar las keys de **hasta 10 organizaciones**: conectás una vez y el asistente trabaja en cualquiera de ellas, o en todas a la vez cuando le pedís un resumen.

---

## Conectar varias organizaciones

### Claude.ai (web) y ChatGPT

<Steps>
  <Step title="Agregá el conector">
    En Claude.ai, **Settings > Integrations > Add custom connector**, con la URL `https://mcp.contactship.ai/mcp`. Ver [MCP en Claude (web)](/es/mcp/claude).
  </Step>
  <Step title="Pegá la primera key">
    En la pantalla de ContactShip que se abre, pegá la API key de una de tus organizaciones. Debajo del campo ves qué organización es.
  </Step>
  <Step title="Sumá las demás">
    Tocá **Sumar otra organización** y pegá la siguiente. Si tenés varias keys copiadas juntas, una por línea, pegalas de una vez: cada una queda en su propia fila.
  </Step>
  <Step title="Conectá">
    El botón dice cuántas organizaciones vas a conectar, por ejemplo **Conectar 3 organizaciones**.
  </Step>
</Steps>

<Note>
Si ya conectaste ContactShip con una sola organización, desconectá el conector y volvé a conectarlo pegando todas las keys. Las keys se guardan cifradas dentro de la conexión, así que no se pueden editar después.
</Note>

### Claude Code

Separá las keys con comas en el mismo encabezado:

```bash
claude mcp add-json contactship '{"type":"sse","url":"https://mcp.contactship.ai/sse","headers":{"x-api-key":"KEY_DE_ACME,KEY_DE_BETA"}}'
```

Si ya tenías la conexión `contactship`, quitala antes con `claude mcp remove contactship`.

### Cursor y Claude Desktop

Lo mismo en `.cursor/mcp.json` o en `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "contactship": {
      "url": "https://mcp.contactship.ai/sse",
      "headers": { "x-api-key": "KEY_DE_ACME,KEY_DE_BETA" }
    }
  }
}
```

## Cómo pedir las cosas

**Para una organización, nombrala:**

> "En Acme, mostrá las conversaciones sin responder de hoy"

**Para ver todas, preguntá sin nombrar ninguna.** Los resúmenes consultan cada organización y te responden por separado:

> "¿Qué conversaciones quedaron sin responder hoy?"

> "¿En qué organización está Ana Pérez y qué pasó con ella?"

Funciona así con las conversaciones sin responder, las tareas, el resumen y la búsqueda de llamadas, la búsqueda de contactos, los agentes, los canales y números, y las métricas del inbox.

**Para cambiar algo, el asistente necesita saber dónde.** Mandar un WhatsApp, editar o publicar un agente, lanzar una llamada o cerrar una conversación siempre se hace en una organización: si no la nombraste, te pregunta en cuál antes de hacer nada.

Para ver qué organizaciones tiene la conexión, preguntale "¿qué organizaciones tenés conectadas?".

---

## Tené en cuenta

- **Cada key sigue viendo solo su organización.** Cada acción se hace con la key de una sola organización, aunque estén todas en la misma conexión.
- **Hasta 10 organizaciones por conexión.** Si necesitás más, usá más de una conexión (ver abajo) o escribinos a [soporte](/es/comenzar/soporte).
- **Si regenerás la key de una organización**, actualizá la conexión: en Claude.ai reconectá el conector con todas las keys; en Claude Code o Cursor reemplazá esa key en el encabezado.
- **Dos organizaciones con el mismo nombre** se distinguen por el comienzo de su id, por ejemplo `Demo (3f2a9c1e)`.

---

## Una conexión por organización

También podés conectar ContactShip una vez por organización, cada conexión con su propia key y un nombre distinto (por ejemplo `contactship-acme` y `contactship-beta`). Sirve si tenés más de 10 organizaciones o si preferís que cada una aparezca por separado. Cada conexión suma al asistente el set completo de herramientas de ContactShip, así que con muchas conexiones elige más lento y usa más contexto en cada mensaje.
